# Ограничения нагрузки

Сборка Android и тяжёлые операции запускаются через `scripts/run-limited.sh`.
Одновременно работает одна операция: общий lock действует для всех программ.

- CPU: суммарно до 210% на трёх доступных ядрах; распределение нагрузки между
  ядрами определяет Linux.
- Память: мягкий предел 2500 МиБ, жёсткий 3 ГиБ, swap отключён.
- Процессы и потоки: не более 128; native-сборка и тесты последовательны.
- CPU и дисковый приоритет понижены. Ядро должно поддерживать cgroup;
  необходим работающий systemd user manager.

Android: `bash build-limited.sh` из `android-player` или `android-hrtf`.
Программы Kubuntu: собственные `setup.sh` и `launch.sh` уже вызывают limiter.
Для остальных тяжёлых команд: `bash scripts/run-limited.sh COMMAND ARGS`.
Код 75 означает, что общая блокировка занята. Не запускайте второй экземпляр
без ограничителя. При нехватке памяти уменьшите объём задания.

Auto у апмиксера использует CPU. CUDA выбирается отдельно и требует совместимых
драйверов и PyTorch; лимит RAM не ограничивает видеопамять.
