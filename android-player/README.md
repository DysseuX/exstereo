# exstereo для Android

Офлайн-плеер от **DysseuX / DysseuX Group** на основе Fossify Music Player 1.8.1.
Версия для публикации: **1.8.1-i18n1 / 32**. Лицензия кода — GPLv3;
сторонние компоненты и HRTF-данные сохраняют собственные условия.

APK в Releases: `exstereo-v32.apk`, тег `player-v32`. Интерфейс выбирает язык
автоматически по первому языку в системном списке Android: `ru` → русский,
любой другой → английский. Ручного переключателя нет.

Основной упор — расширение стерео и виртуальное 7.1 в обычных наушниках.
Внутри 11 алгоритмов расширения, FreeSurround / PAE-PAD / FFmpeg surround для
upmix, Steam Audio / OpenAL Soft / sofalizer для бинаурального вывода.
Можно менять положение виртуальных колонок, HRTF и отражения комнаты.

30-полосный эквалайзер работает во всех режимах: 25 Гц–20 кГц, ±12 дБ,
с запасом по уровню при усилении полос. Библиотека содержит треки, папки,
исполнителей, альбомы, жанры и плейлисты, поиск, сортировку и импорт плейлистов.

Требуется Android 8.0+, arm64-v8a или x86_64. Root не нужен. Точный минимальный
процессор не определён; скорость и качество нужно проверять на своём телефоне.
В APK нет Demucs и ITSADIVE: эти модели используются отдельными программами.

Выход всегда стерео для наушников. 5.1/7.1 обрабатываются без повторного upmix.
44,1/48 кГц сохраняются, более высокие частоты перед DSP приводятся к 48 кГц;
выход PCM16. Dolby Atmos object rendering, MPEG-H и head tracking отсутствуют.
OpenAL использует свой HRTF; выбор SOFA относится к Steam Audio и sofalizer.
